# Maternal Health Risk Classification using Machine Learning

## Overview
This repository contains the implementation of a machine learning model for maternal health risk classification.
The associated research paper has been submitted to a journal and is currently under review.

## Dataset
The dataset used in this study is publicly available at:
https://data.mendeley.com/datasets/p5w98dvbbk/1

## Methodology
- Data preprocessing and normalization
- Machine learning / deep learning model implementation
- Performance evaluation using standard metrics

## Technologies Used
- Python
- NumPy
- Pandas
- Scikit-learn

Paper submitted (under review)
